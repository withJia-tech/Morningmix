# MorningMixer × Codex — five-slide talk

Five content slides, one main message per slide and exactly three supporting points per slide.

## Open the presentation

[View the standalone web slides](./index.html). Download the HTML file and open it in any modern browser.

- Arrow keys / space: change slide
- **Notes** or **N**: speaker notes
- **⛶**: fullscreen
- No external fonts, scripts, network calls or trackers

## Slide messages

1. **Start with what you know. Codex makes it buildable.**
2. **A good idea becomes testable when its rules are explicit.**
3. **The phone proposes an action. Only the engine commits it.**
4. **A passing simulation is not a passing iPhone test.**
5. **Build faster. Challenge assumptions. Verify the result.**

## Provenance and scope

Based on `README.md`, `ARCHITECTURE.md`, and `TESTING.md` on the Morningmix main branch as inspected 11 November 2026.

- This is an **AI-assisted development** story. MorningMixer does **not** invoke an LLM or an AI agent at runtime.
- The project's 8 November 2026 test.8 record reports 81 passing synthetic tests and one known TODO, with actual phone acceptance still open. This presentation did not run those tests or establish new hardware evidence.
- No application code, assets, or GitHub Pages deployment workflow was changed to add the talk. The talk is on this separate branch.
- The existing playable site remains [the MorningMixer preview](https://withjia-tech.github.io/Morningmix/). It is a test candidate, not a sensor-verified production release.
